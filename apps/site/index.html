Features

Everything a small team needs to ship, on a server you own.

Each card says what works today and what lands in v0.1. No surprises.

  • v0.1

    Git push to deploy

    Connect a GitHub App or a GitLab token in a few clicks. Every push builds and ships, with the result posted back to the commit.

  • v0.1

    Automatic HTTPS

    Point a domain at your server and Traefik gets a Let's Encrypt certificate for it. Renewals happen on their own.

  • v0.1

    Zero downtime and rollback

    The new version starts and passes its health check before traffic moves. One click takes you back to the last good deploy.

  • v0.1

    Databases and backups

    PostgreSQL, MySQL and Redis next to your apps, with scheduled backups to any S3-compatible storage.

  • Works today

    Projects and a clean panel

    Group apps into projects. A fast panel with light and dark themes, built for the phone as well as the desktop.

  • Works today

    Secure by default

    Argon2 passwords, httpOnly sessions, rate-limited login, strict security headers and an audit log of every change.

How it works

From a clean server to a live app in three steps.

  1. 01

    Install with one command

    The installer checks the server, sets up Docker and starts Nocap, Postgres and Traefik. Then you create your admin account in the browser.

  2. 02

    Connect GitHub or GitLab

    Pick the repository and branch. Nocap builds from your Dockerfile or Docker Compose file, so there is nothing new to learn.

  3. 03

    Push and it is live

    Each push deploys with HTTPS on your domain. Watch the logs as it builds and roll back if something looks wrong.

FAQ

Questions

Is it really free? +

Yes. Nocap Cloud is open source under the Apache 2.0 license. There are no paid plans, no limits and no account to create. You only pay for your own server.

What server do I need? +

Ubuntu 22.04 or 24.04 on amd64 or arm64, with at least 1 GB of RAM (2 GB recommended, because builds need memory) and 20 GB of disk. Ports 80, 443 and 3000 must be free.

Can I use it in production today? +

Not yet. The project is in early development and deploys arrive in the next phases. Star the repository to follow the first release.

Does it send data anywhere? +

No. There is no telemetry and the panel loads no third-party scripts or fonts. Everything stays on your server.

How is it different from Coolify or Dokploy? +

Same idea, written from scratch in TypeScript with a focus on a small footprint: three containers, no Redis, and one image for the whole panel.
