Contribute

Your first pull request

TypeScript from end to end, small modules and tests for everything. You can run the panel in demo mode without a server or a database.

  1. 1. Pick

    Choose an issue

    Start with one labelled good first issue, and say you are on it.

  2. 2. Run

    Start it locally

    pnpm install
    pnpm --filter @nocap/web dev:demo
  3. 3. Check

    Keep CI green

    pnpm lint
    pnpm typecheck
    pnpm test
  4. 4. Send

    Open a pull request

    Use the template, link the issue and add a screenshot for panel changes.

Support

Free forever. Help keep it going.

Nocap Cloud has no paid plans and never will. Funding will pay for test servers and time spent on the project. It opens after the first release.

  • Star the repository

    It helps other people find the project.

  • Report a bug

    Clear steps to reproduce are gold.

  • Share it

    Tell a friend who still deploys by hand.

  • Write about it

    A post or video about your setup helps a lot.
