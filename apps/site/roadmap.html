Roadmap

A tree that grows one version at a time.

The trunk is the main branch. Each version is a branch, and its features are the leaves. Filled leaves are done. Pre-releases grow on a side branch and join the trunk at v0.1, the first release you can install.

How a version ships

    Semantic versions. v0.x until the API is stable.

  2. 2. Build

    Images for two CPUs

    GitHub Actions builds amd64 and arm64 and pushes to GHCR.

  3. 3. Publish

    Release notes

    A GitHub Release with the changelog, installer and compose file.

  4. 4. Update

    One click for you
