# Code of Conduct

Nocap Cloud follows the
[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, assume good intent, and keep discussions about the work. Harassment,
insults and personal attacks are not accepted in issues, pull requests, discussions or any other
project space.

To report a problem, contact the maintainers privately through the email listed on the
maintainers' GitHub profiles. Reports are handled confidentially.
